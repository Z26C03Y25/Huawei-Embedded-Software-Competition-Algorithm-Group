## 行为

- 已知位置表为30、202、213、586、662、774，均为0-based。
- 默认粗扫8格；550以后使用12格连接，同时在经过已知点时插入该点及左右邻点。
- 已知点顺序处理；判定停车前不跨越下一个未处理的近邻候选。
- 202与213相距11格，先比较完这组近邻，再尝试在202附近早停。
- 已知点有严格左右峰形、左侧上升支持、对比度足够时尝试提前停车。
- 未满足已知点规则时，使用半高宽、下降与回升证据判断继续探索或转入精修。
- 位置表模式遇到平坦前缀，会继续探后续已知点，避免662/774孤立峰直接漏查。
- 模型精修由加权二次拟合、钟形峰、非对称宽度、三角峰、区间内窄峰等虚拟曲线
  生成不同目标假设，枚举局部连续查询窗口及两种访问方向，按模拟Q/M/O/R和
  200*d损失比较净收益。虚拟曲线都保留已观测原始值，并非校准过的真实概率分布。
- 所有原始读数参与赢家和平局判断；稀疏结构点单独用于粗趋势和噪声统计。
- 每次非终端查询预留最终真实停车，最多199次查询、6次振荡。真实冗余与命中
  依赖启发式，无法对任意未知数组保证。模拟器得分也没有套用未解释的29分修正。

## 编译运行

项目内便携JDK已放在dev/toolchains/temurin21，无需修改环境变量。在仓库根目录执行：

```powershell
& '.\dev\toolchains\temurin21\jdk-21.0.13+9\bin\javac.exe' --release 8 -encoding UTF-8 .\temp\hybrid\Main.java
& '.\dev\toolchains\temurin21\jdk-21.0.13+9\bin\java.exe' -cp .\temp\hybrid Main
```

直接运行是交互模式：先输入N，每收到一个下标就需回复该点原始值。
自动本地机制检查：

```powershell
& .\python\runtime\python.exe -X utf8 .\temp\hybrid\check.py
```

控制变量开关，正式默认均开启：

- `--no-prior`：关闭已知点表，保留通用拟合/精修。
- `--no-fast-stop`：保留位置表，关闭已知点快速停车；远端允许先比较仍在当前
  已观测赢家199格范围内的后续已知点。通用停止条件依然存在。
- `--trace`：诊断计数输出到stderr，stdout仍只含交互协议。

该消融比较整个策略的实际表现；开关会改变观测与路径，不是完全相同查询轨迹
上的纯收益差。在线提交不能传命令行参数，平台运行本文件的默认混合策略。
