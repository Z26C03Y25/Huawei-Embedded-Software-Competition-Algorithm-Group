# 自动聚焦：搜索算子库、分支决策树与预算设计

设计日期：2026-10-24。本文保留编写代码前的策略设计；后续经用户明确授权，已改写 main.cpp，实现映射和运行方式见《策略实现说明.md》。依据仓库内原始赛题 PDF 的关键定义、平局规则与评分规则；参数区间均为待验证的设计候选。

## 1. 先把优化问题写对

设真实数组为 f，长度 N，查询轨迹为 x1…xQ，初始位置 x0=0。真实主峰 p* 按“原始值最大、离中心最近、仍同距取较小下标”确定。

| 量 | 定义 | 得正分的必要条件 |
| --- | --- | --- |
| Q | 实际输出查询并读取应答的次数，重复位置也计数 | Q ≤ 199 |
| M | Σ abs(xk-x(k-1)) | 进入搜索时间 Q+M |
| O | 非零移动方向的反转次数，第一次读取不计振荡 | O ≤ 6 |
| r | 历史查询到达的最右下标 | 只增不减 |
| R | max(0,r-p*) | R ≤ 199 |
| d | abs(xQ-p*) | d ≤ 3 |

在这些条件成立且正常完成交互时，单例得分为 max(0,3000-200d-Q-M-O-R)。每例另受 10 秒和 512 MB 限制。

**搜索步数不是移动距离。** 一次跳到 500，只增加一次查询，却会产生移动成本；若真实峰在 100，还会立即触发冗余零分。返回左侧不能减少 r 或 R。

**最终停车必须是真实查询。** 内存中更新 best_idx、读取缓存、输出 DONE，都不会把电机移到最佳点。

**题面给的是固定数组。** 背景中的“噪声、运动干扰”在本题表现为数组形状。重复读取同一位置不会得到新的独立噪声样本，不能用重复测量取均值来消噪。

## 2. 什么能严格保证，什么需要曲线假设

### 2.1 可以对每一次真实动作严格控制的部分

通过唯一查询入口、完整轨迹模拟和停车预算，可以严格保证下标合法、Q≤199、O≤6，以及最后输出 DONE。运行时间应设置内部截止时间，预留完成交互的余量；不能把操作系统和判题器的响应耗时视为完全可控。

### 2.2 冗余与全局命中的信息限制

不能对题面允许的任意数组，同时保证少于 200 次查询、找到全局峰并满足 R≤199。

例如 N≥400、此前所有查询都返回 0：199 次查询后仍有至少 201 个未采样位置，其中必有位置在最终停车的 ±3 范围之外。把该位置设为 1，其他位置设为 0，交互历史不变，但算法停错。

冗余也有冲突：若 0 处值为 1、其他已查位置为 0，向右越过 199 可能让“真实峰仍是 0”的数组归零；完全不越过，又可能错过更右侧值为 2 的隐藏主峰。

因此需要明确区分以下三种边界，禁止混用：

| 边界 | 含义 | 能否称为硬保证 |
| --- | --- | --- |
| 已观测最佳点 b | 已查位置中按正式规则最好的点 | 不能用 r-b≤199 推出真实 R≤199 |
| 模型竞争区左端 Lmodel | 根据峰形、噪声和采样覆盖推断的主峰可能左界 | 只能称为模型风险控制 |
| 证明有效的左界 Lcert | 由取值范围和已观测信息证明 p*≥Lcert | r≤Lcert+199 时可严格保证冗余 |

一种保守的证明方法：维护真实目标的候选超集 Ccert。通常保留所有未查询位置，加上按正式规则最好的已查位置；已查且被它严格击败的位置可移除。取 Lcert=min(Ccert)，则 r≤Lcert+199 是充分安全条件。它通常很保守，但不会把统计推断冒充证明。

若已查到 2^31-1，则不存在更高值，未查位置只有在同值且平局优先级更高时才可能替代它，此时可进一步收缩 Ccert。若数组较小的中央下标 floor((N-1)/2) 已查到 2^31-1，目标已经得到严格证明，可直接停车。

### 2.3 历史冗余会永久淘汰一部分目标

当前 r 决定可得正分的真实目标必须满足 p*≥F，其中 F=max(0,r-199)。F 是“可得分目标下界”，不是“真实主峰下界”。

若后来发现一个很高的左峰 b<F，不能把 b 从候选表删除后，选择另一个较低右峰来宣称安全。这个左峰仍可能是真实主峰；只有发现更高值，或发现同值且正式平局规则更优的位置，才可能改变真实目标并恢复得分机会。任何算子都无法撤销既有右探历史。

## 3. 推荐架构：状态识别与电机执行分开

每轮执行以下流程：

1. 从已有数据更新特征、峰候选、模型分歧与预算，无真实查询。
2. 按决策树激活少量匹配算子，生成候选采样计划。
3. 必要时在内存中通过模拟退火或局部搜索调整计划。
4. 将计划展开为完整有序轨迹，连同停车动作审核 Q、O、M、r。
5. 只执行下一个短批次，读取新信息，再回到第 1 步。

不把所有算子按顺序跑一遍，不在每次观测后重新执行一段左右爬山。算子库可以丰富，单例实际启用的算子应保持少量。

### 3.1 状态至少包含哪些信息

- 交互状态：N、当前位置、最后非零方向、Q、O、M、r、缓存、耗时。
- 目标状态：原始最佳位置和值、平局优先级、尚未排除的旧峰。
- 曲线状态：局部趋势、残差尺度、量化程度、峰宽、峰显著性、平台边界。
- 覆盖状态：采样间距、最大空洞、候选区内未查点数、左右肩支撑情况。
- 不确定性：多个模型是否同意、竞争峰高度是否可区分、还有哪些未探区域。
- 资源状态：停车预算、验证预算、允许新增反转数、模型允许的前探余量。

趋势必须按真实下标差计算斜率。噪声尺度可参考不等距三点插值残差的中位数或 MAD，但要防止把曲率、量化台阶或第二峰误当噪声。它们都是观测统计，不是官方给定噪声上界。

原始值通道用于决定目标；平滑通道用于识别结构。原始异常高点必须保留，不能因为“看起来像噪声”就丢弃。

### 3.2 分层决策树

```text
接收 N，初始化账本
│
├─ 能否证明全局最优目标？
│   └─ 中央位置达到数值上界等证书成立 → 直接停车
│
├─ 资源或协议状态是否要求收尾？
│   ├─ 再查询会侵占停车预算 → 停车
│   ├─ 再反转会使完整收尾轨迹超 6 → 禁用该分支
│   └─ 时间接近内部截止线 → 最短合法停车
│
└─ 小范围、向右的初始观察
    │
    ├─ 观测上近似平坦
    │   ├─ 尚未接近中心 → 受控前探，同时保留迟起峰假设
    │   ├─ 接近中心且长期平坦 → 中央平局分支
    │   ├─ 平坦后出现持续抬升 → 迟起峰分支
    │   └─ 平坦区只有孤立高点 → 尖峰分支
    │
    ├─ 持续上升
    │   ├─ 斜率稳定、噪声低 → 中步长推进
    │   ├─ 斜率减小/出现肩部 → 缩步、准备峰区夹逼
    │   ├─ 高噪声下平均上升 → 趋势推进、保留原始候选
    │   └─ 接近右端仍上升 → 右边界分支
    │
    ├─ 持续下降
    │   ├─ 初始左侧已经最高 → 左边界保护
    │   ├─ 明显峰后可信下降 → 局部精修或停止
    │   ├─ 下降幅度小、峰顶宽 → 宽峰/平台分支
    │   └─ 下降后再次抬升 → 双峰/多峰分支
    │
    ├─ 多次有效升降
    │   ├─ 可辨识的多个峰区 → 多候选分配
    │   ├─ 宽高值区内细碎起伏 → 宽噪声峰覆盖
    │   ├─ 单点或极窄原始高点 → 尖峰与网格混叠检查
    │   └─ 无稳定结构 → 低置信度、多尺度保守搜索
    │
    └─ 分支模型互相矛盾
        ├─ 增补最能区分假设的点
        └─ 撤销平滑单峰假设，回到候选区覆盖

每个叶节点再细分：
位置〔左边界/内部/右边界〕
× 宽度〔极窄/普通/宽峰/平台〕
× 噪声〔低/中/高/无法估计〕
× 拓扑〔单候选/竞争候选/迟起未探〕
× 资源〔充足/查询紧/反转紧/前探风险高〕。
```

这些维度形成条件组合，但不硬编码全部笛卡尔积。由“主状态 + 修饰条件 + 算子准入条件”组合，可避免分支爆炸。状态切换要求持续证据；结构突变可触发立即降级，不能因滞回机制强行坚持旧模型。

## 4. 96 个候选算子

以下分为 12 类，每类 8 个。它们覆盖特征、真实取样、轨迹、控制和内部优化；不是 96 个都需要真实查询的独立搜索器。

统一接口应包含：输入状态、触发条件、候选位置或轨迹、最大新增查询、完整方向序列、增加的最右位置、预计收益、依赖假设、失败退路。表中的“风险”既用于设计审查，也用于安排反例测试。

### A. 特征与假设算子：不消耗查询

| 编号 | 算子 | 触发与动作 | 风险/限制 |
| --- | --- | --- | --- |
| A01 | 不等距斜率 | 依据相邻点的值差/位置差估计上升下降 | 相隔很远时不能代表区间内部 |
| A02 | 稳健残差尺度 | 用三点插值残差估计局部与历史波动 | 曲率和台阶也产生残差 |
| A03 | 趋势一致性 | 统计多段显著同向变化，排除微小波动 | 不会证明远处没有第二峰 |
| A04 | 曲率与肩部 | 检查斜率递减、递增和转折 | 噪声高时仅降低或增加置信度 |
| A05 | 峰显著性 | 相对两侧谷值和局部基线计算突出程度 | 高而窄的峰不应被平滑抹掉 |
| A06 | 多高度峰宽 | 估计半高宽及接近峰顶区间的宽度 | 单侧未观测时标为截断估计 |
| A07 | 量化与平台识别 | 统计相等值、台阶长度和微小级差 | 采样全相同不等于全数组常数 |
| A08 | 覆盖与模型分歧 | 标注大空洞、模型预测差异和候选重叠 | 一致预测也可能共同漏掉尖峰 |

## 6. 三项强制阈值如何贯穿所有算子

### 6.1 查询预算：每个算子都服从同一个账本

对于计划新增 k 次查询，必须满足 Q+k+Qfinish≤199。Qfinish 是当前计划之后真正需要的收尾次数，不能总是假设为 0。

若结束只需回到一个已查最佳点，Qfinish 为 0 或 1；若规定还要补查邻域，邻域未查点数和最终回位都要包含在内。预留一次停车不能支付任意长度的 finish 逻辑。

下面是一组加总恰为 199 的初始配额示意，不是固定参数或必须花完的任务：

| 阶段 | 查询额度 |
| --- | ---: |
| 初始识别 | 8 |
| 前向粗探 | 64 |
| 竞争峰验证 | 24 |
| 局部/宽区精修 | 86 |
| 异常恢复或补洞 | 16 |
| 最终停车 | 1 |
| 合计 | 199 |

单峰通常无需多候选验证，可把额度转给精修；左端峰可提前结束；宽区需要的点多时可以借用未花的前探和异常额度。阶段配额不是绕过总预算的多个独立上限。

### 6.2 反转预算：规划方向阶段，而非限制函数调用次数

默认轨迹优先使用：向右粗探 → 向左精修 → 回最佳点。最多两次反转。确需第二轮时，可以采用向右粗探 → 向左补采 → 向右细采 → 停车，完整轨迹通常最多三次反转。

“最多几次”必须由实际下标序列证明。当前位置处于待查区内部、跨区入口或最终停车，都可能新增反转，不能仅数“精修轮数”。

常规探索可采用 O≤4 的工作余量，剩余两次仅供通过完整轨迹审核的恢复或收尾；若邻域补查需要更多反转，则裁掉邻查，保留合法停车。允许使用第 5、6 次反转，但必须有明确收益并证明最终不出现第 7 次。

反转在未达到阈值时只扣 1 分。值得的验证不应被“绝不多转一次”机械阻止；但频繁折返还增加移动成本，并减少后续决策自由度。

### 6.3 冗余预算：按真实风险而非观测最佳点检查

对下一位置 x，先计算 r'=max(r,x)。

- 严格模式：有证明下界 Lcert 时要求 r'≤Lcert+199。没有更强证书时，可限制 r'≤199，但这会放弃许多右侧主峰。
- 模型模式：维护 Lmodel 和竞争左峰，限制 r'-Lmodel。可用 120、150、180 等前探余量做候选实验；这些不是题目常数，也不保证隐藏峰安全。
- 若有经校准的主峰位置模型，可评估 P(p*≤r'-200 | 已观测历史)。它才对应此次最右位置造成的冗余失败事件。没有校准数据时，只使用风险分级，不报告虚假的概率。
- 所有跳跃必须在查询之前审核。当前距离为 185、下一跳 24，不能先走到 209 再处理。
- 新观测把竞争区移向更左时，应重算历史失分风险。新的模型边界不会重置历史 r。

宽峰优先用整个竞争区的左端，而非最高粗采样点作模型锚。原始最大值可能藏在宽区左侧，几个噪声点就能把已观测最佳位置推到很右边。

## 7. 模拟退火放在哪里才合适

### 7.1 不建议直接对真实电机位置做退火

若以“随机走一个位置，读取值，接受或拒绝”为算法，每次拒绝也已经花掉查询和移动，且 r 不会退回。典型退火中的大量邻域尝试不适合直接消耗这 199 次交互。

### 7.2 在线：优化未执行的采样计划

退火状态包括：候选窗口、每区采样额度、采样位置、步长序列、停止深度和算子组合。固定点集的一维访问顺序优先使用排序和少量方向阶段，不为了使用退火而把简单路径问题复杂化。

输入只有已经观察到的点、缓存、模型与预算，不能读取真实未查询数组。对若干合理曲线补全情景，模拟计划及后续动作，使用完整正式评分得到情景得分。

目标可取“情景平均得分 - 风险厌恶系数×尾部损失度量”。这里的系数与情景权重需要留出验证。没有校准分布时，这只是模型目标，不能宣称实际期望分。

Q>199、O>6、下标非法等确定不可行方案直接淘汰，不以有限罚分允许退火暂时穿越。真实冗余未知时，使用前述证书或模型风险；不能用模型均值峰位替代真实 p* 来宣称可行。

使用 L01—L08 产生邻域。若最大化目标 J，改善方案直接接受，较差方案以 exp((Jnew-Jold)/T) 的概率接受；始终保留最好的可行计划。停止由剩余时间和收益决定，不要求每次执行固定大量迭代。

只执行胜出计划的第一个短批次，得到真实应答后再规划。一次性提交很长的不可撤销轨迹会错失新信息带来的调整机会。

### 7.3 离线：调整策略参数与算子组合

获得完整曲线后，可用模拟退火搜索步长、显著性阈值、窗口额度、状态切换门槛及模型前探期限。每条曲线都完整模拟真实查询顺序、停车和正式评分。

训练集、调参集和留出集按曲线来源或场景隔离；不能把同一条曲线改一点噪声就当独立数据。正式评测仅有总分时，严格保存每次源码与哈希，避免大量同时改动后无法归因。

内部随机数种子应固定或可重放，以便比较。随机化是改善失败分布的工具，不提供对所有数组的保证。

## 8. 评分导出的几个重要取舍

### 8.1 精确停车的价值很高

在已命中同一真实峰、其他量不变时，停车误差少 1 可多 200 分。花少量查询和移动把 d 从 1 降为 0，往往值得。但必须估计确实改善真实目标位置，不能把拟合位置当真。

若能证明 p* 位于整数区间 [l,u] 且 u-l≤6，停在该区间的合适中点可保证 d≤3；这只解决停车容差，不解决其他隐藏峰或冗余。要争取 d=0 仍需进一步识别区间内原始最大值。

步长为 6 只意味着几何上任意位置靠近某个网格点，不保证“采样值最大的网格点”靠近真实主峰。

### 8.2 不必要的右探可能同时多扣三类代价

在向右到 r、向左扫至 l、再停到 b，且 0≤l≤b≤r 的轨迹中，移动总量为 M=2r+b-2l。固定 l、b 继续向右多走 Δ，移动增加 2Δ；若目标不变且冗余为正，冗余再增加 Δ，合计约多扣 3Δ，另加新增查询。

同理，回程扫到 b 左边额外 Δ 再返回 b，会多出 2Δ 的移动。局部密查不仅有查询费，也有跨过最终目标再折返的费用。

### 8.3 有价值的是“增加正分概率”，不是一味少查

几十步合理验证可能救回一个原本 0 分、可得两千多分的用例。相反，完全平坦时过度右探可能让已经能在中央停车的用例归零。

因此比较策略时要同时记录平均/总分、正分率、失败原因，以及条件成本。近似的“增益概率×可救回得分”只能帮助判断数量级，正式比较仍需完整轨迹和正式评分。

## 9. 起始点、早停与参数的具体建议

### 9.1 “第一次取 100”可以作为候选，不能由 200 阈值直接推导最优

第一次查询 100，因 p*≥0，当前冗余最多 100，确实不会立即触发 200 的阈值。但它没有提供 [0,99] 内部形状，也不允许后续忽略早期左峰。

若之后继续走到 250，真实峰仍在 0，则已经归零。往回精修不能恢复。

建议比较两类起始方案：

- 保守左端方案：例如 0、4、12、24，依据观测再调步长；这些只是候选位置。
- 少量左端哨兵后向右的方案：识别初始下降风险后，再决定是否跳到 64/96 一带。

没有场景先验时，不建议一开始从中央或右端大跳。N 只决定范围，不能告诉我们主峰在哪。

### 9.2 早停应是证据组合

可信局部早停可组合：显著原始或趋势峰已出现、连续有效下降、没有持续回升、峰区已经得到足够覆盖、多个合理模型大体同意、继续前探的收益不足以抵消风险。

其中任何一条单独都不足以证明全局正确。特别是“下降一次”“连续三个低点”“离 best 超过某距离”，都不能排除更远更高的峰。

### 9.3 分类阈值应无量纲化

斜率显著性相对局部残差；峰高相对局部基线和波动；步长相对估计峰宽与未查间隔。不能用 best_value×0.95 等绝对比例覆盖所有曲线：很高的常量基线会让相对峰值差被掩盖。

残差接近零时需要独立处理量化、全等值和光滑曲率，不能简单除以一个几乎为零的数得到过度自信。

## 10. 改造前源码的设计风险（历史记录）

编写本设计时的 main.cpp 与仓库 README 描述的版本不同。该原始文件现保存在 data/versions/main_before_strategy.cpp，下列静态结论针对该备份。

从静态结构看，当前源码在向右查询下降后调用 refine(prev_idx,next)，先退回区间内部，再向右查询；反复调用会反复消耗方向反转。MAX_REFINE=5 并不等价于振荡不超过 6，finish 的邻域与回位也必须计入。

当前 Q_LIMIT=170 给精修和 finish 留了保守余量，不能仅因缺少统一入口就断言一定超过 199；其每轮最多 15 个内部补点、最终至多 7 个邻域点加一次回位，按当前控制流可推得保守上界 193。后续增加任何算子后，这种分散的隐式余量很容易失效，因此设计上仍应改为统一账本。

max_right-best_idx 的检查只是观测最佳点的距离，也没有在每次右跳之前统一检查拟议 r'。它不能证明真实冗余安全。

上述结论是本轮静态阅读所得，不代表已经对当前版本重新编译、运行回归或取得新正式成绩。

## 11. 验证矩阵：先验证不会白白归零，再比较增益

### 11.1 硬边界与轨迹检查

- 199/200 次查询的边界，包含重复停车和精修追加。
- 6/7 次反转的边界，包含零位移后方向保持、邻域入口与最后回位。
- 199/200 格冗余的边界，以及一次跨步直接越界。
- 停车误差 0、1、2、3、4；相同原始最大值的中央优先级。
- 常数、全零、极大整数、偶数中心的两个下标、左右端点。
- 完整计划可执行但前缀执行后需要重规划的场景。

### 11.2 结构参数的系统覆盖

| 维度 | 必须变化的内容 |
| --- | --- |
| 长度 | 400、中间长度、1000，奇数与偶数 |
| 峰位置 | 左端、左前段、中央、右后段、右端 |
| 峰宽 | 1、2、3、接近粗步长、普通宽峰、超过精修额度 |
| 对称性 | 左陡右缓、左缓右陡、截断峰 |
| 噪声 | 无噪声、细小噪声、高噪声、异方差、固定锯齿 |
| 基线 | 低背景、高背景、倾斜背景、长量化平台 |
| 多峰 | 左高右低、左低右高、等高、近间距、远间距、三峰以上 |
| 平台 | 跨中央、不跨中央、顶端微尖点、平台外孤立更高点 |
| 混叠 | 峰落在网格点、间隙中央、多个间隔同相漏检 |
| 迟起 | 长零背景后窄峰、长非零常量后宽峰 |

每次失败应同时记录所有零分原因，不能只按第一个原因归类。报告包含原始完整曲线、查询轨迹、真实目标、Q/O/R/d/M、分支和算子序列。

### 11.3 算子消融与版本选择

先比较受控的策略差异：基础分支、增加宽区覆盖、增加迟起侦察、增加双峰验证、再增加内部计划优化。每次看救回多少例、损失多少例、成本变化以及对应结构。

96 个算子是候选库。先实现高收益且能验证的核心子集，再用消融结果决定是否增加复杂分支。代码复杂度、参数数量和交互时间也是需要支付的成本。

合成数据用于检查失效模式，不能替代真实 102 个用例，也不能把合成总分当正式得分预测。没有新评测时不承诺提分幅度。

## 12. 后续实现顺序

1. 单一交互入口、查询/方向账本、真实停车、历史最右位置审计。
2. 单调粗探与单调回程的基本轨迹。
3. 原始/趋势双通道、平坦/上升/下降/多峰状态。
4. 左边界、常数/迟起冲突、宽噪声峰三类专项分支。
5. 尖峰、双峰、平台平局与数值上界证书。
6. 候选区配额和有限第二轮精修。
7. 证明与模型边界分离，完整记录失败原因。
8. 有足够曲线和清晰模型后，再加入内部模拟退火与离线参数优化。

第一轮的关键成果应是：每个分支的适用条件明确，所有真实动作可支付，所有统计假设可追踪，所有归零原因可复盘。算子的数量服务于覆盖不同失败结构，而不是单例执行量。
