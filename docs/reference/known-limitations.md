# 已知限制与研究问题

[文档导航](../README.md) · [正式总结](../持续线上优化总结.md)

## 当前实现的边界

- Q≤199、O≤6及停车预留由执行入口控制。
- 默认冗余控制依赖峰形模型，不能保证任意隐藏主峰的真实R≤199。
- 严格冗余模式使用证明左界，但会牺牲远端覆盖，不保证命中。
- 重复读取固定数组值不能独立降噪；平滑值不替代最终原始值排序。
- 虚拟场景和拟合不是官方曲线分布，也不是经校准的全局证书。

## 保留的反例

| 结构 | 当前问题 | 值得研究的方向 |
| --- | --- | --- |
| 长零前缀后才出现远端峰 | 平坦期限提前结束 | 覆盖/冗余的证据权衡 |
| 宽平台内201点隐藏最高值 | 边缘少量点未查完 | 在反向前补齐小竞争单元 |
| 宽趋势叠加中等独立噪声 | 不显著而过度向右推进 | 危险线前有限验证、多尺度特征 |
| 大间隔内尖峰 | 插值场景低估潜在极值 | 区间不确定性与结构场景 |

原始断言仍在[test_strategy_solver.py](../../dev/tests/test_strategy_solver.py)。运行诊断查看最新失败，不把上述合成案例认作已定位的官方失败曲线。

## 尚未验证的方向

最后+882分同时修改模型收尾与常规半径；独立贡献尚待消融。更小窗口、更多竞争区和新退火场景也不能在正式实验之前称为有效改进。见[下一轮分析](../下一轮优化分析.md)和[外部建议审查](../外部优化建议审查.md)。

## 工具与复现边界

线上工具依赖专用Chrome会话、平台页面结构和本人授权。平台变化时只读/提交可能需要适配，离线测试不会证明网站未来不变。

旧实验包含本地路径；浏览器profile、账号和runs任务不随仓库共享。Linux离线命令可用的设计与CI配置，不代表浏览器自动化已经在所有系统实测。当前采用Python 3.10+和GCC C++17，未适配原生MSVC。

没有配置项目许可证，没有包含官方隐藏数据，没有保证达到某个分数或排名。
