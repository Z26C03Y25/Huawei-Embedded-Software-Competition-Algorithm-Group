# 问题与评分：先优化真实轨迹

[文档导航](../README.md) · [原始赛题](../../data/problem/README.md)

## 一次交互是什么

```text
裁判 → 求解器：N
求解器 → 裁判：idx，再立即刷新输出
裁判 → 求解器：该位置的固定原始值
……
求解器 → 裁判：DONE
```

DONE不包含停车下标。查询过某点并把值放进缓存，不等于电机现在就停在那里。重复查询同一点不会产生独立噪声样本。

## 评分中的五个量

设真实目标为t，查询序列为x₁…xQ，x₀=0，最终位置为xQ。

```text
M = Σ |xₖ-xₖ₋₁|
O = 非零移动方向的反转次数
R = max(0, max(x₁…xQ)-t)
d = |xQ-t|
```

Q≤199、O≤6、R≤199、d≤3且其他协议、时限和资源要求满足后：

`score=max(0,3000-200*d-Q-M-O-R)`。

同位置查询不改变移动方向，初次产生方向不算振荡。Q是读取次数，不是走过的格数，也不是退火迭代次数。

## 手算一条轨迹

题面12点示例为 `[10,14,15,16,17,12,10,8,8,9,6,5]`，真实最大值在4。假设查询 `0→4→8→4`：

| 指标 | 值 | 原因 |
| --- | ---: | --- |
| Q | 4 | 四次真实读取 |
| M | 12 | 0+4+4+4 |
| O | 1 | 从向右变为向左 |
| R | 4 | 曾到8，目标在4 |
| d | 0 | 最后真实查询4 |
| 分数 | 2979 | 3000-4-12-1-4 |

回到4能修复停车误差，但不能把历史冗余4变回0。先前若已经越过真实目标200格，之后返回也无法恢复该例分数。

## 平局如何选择

在所有原始最大值位置中，最小化 `(abs(2*i-(N-1)), i)`。N=1000且全数组恒定时，目标为499。平滑趋势峰、较宽的峰和较早遇到的峰都不替代这一规则。

## 能证明什么

当前统一入口可以硬控Q、O和停车预留。真实目标在未读区域时，默认模式的冗余边界依赖峰形假设。

两条数组可以在已查询位置上完全一致，却在不同的未查询位置藏有更高值。有限采样不能同时保证任意数组全局命中和全部预算。严格模式保留未读点构成的证明候选集合，用其最左位置限制右探；代价是可能无法覆盖远端。

这一信息边界决定了算法需要实验而非只需要更多分支。继续阅读[源码导读](solver-walkthrough.md)与[已知限制](../reference/known-limitations.md)。
