# 以减少漏峰零分为重点的分类协作方案

2026-10-31。设计提案，尚未实现或取得新正式成绩。承接[特征分析](feature_dimensions_20261030.md)和[区间控制器](decision_architecture_20261030.md)。本轮没有启动上传。

## 1. 目标与能力边界

目标仍是提高包含零分的综合得分，但新结构首先检验能否修复漏峰、错误停车及过度右探造成的零分。分别记录修复零分、新增零分和非零样例的成本变化；不能把大量样例普遍降分解释为防守成功。

Q≤199不能穷尽400～1000个位置。任意未读位置均可能存在单点最高值，故“所有任意数组均不漏峰”无法保证。可做的是针对不同结构采取不同动作，并明确未解决风险。没有官方逐例数据，不能从210599总分断言当前有多少零分、是什么类型。

零分风险必须分开：

| 风险 | 能否精确预防 | 设计响应 |
|---|---|---|
| Q≥200、O≥7、超时或交互错误 | 可以按自身行为控制 | 每个动作审核完整路线和停车，留时间余量 |
| 真峰未读、最终误差>3 | 一般不能全局保证 | 多候选、空隙审计、原值核查 |
| 最右位置超过真目标199格 | 真目标未知，不能普遍保证 | 前沿承诺检查，避免局部验证被推迟到失效后 |

## 2. 分类是动作选择，不是提前给整条曲线贴标签

每个区间同时允许多种解释。所谓“平滑峰策略”仅在对应区间证据足够时启用；新点可以撤销它，未知型始终有入口。宽峰上叠窄峰、平台上叠尖点、近邻双峰都不能被单一分类覆盖。

| 可观测结构及有效性 | 主动作 | 必须保留的防漏动作 | 禁止的捷径 |
|---|---|---|---|
| 多个物理尺度趋势一致，两肩已观察，局部模型可预测留出点 | 平滑峰：模型只提出少量验证位置 | 原值候选附近及模型分歧处检查；低端点空隙仍可审计 | 直接停车拟合顶点；拟合好就宣布无其他峰 |
| 孤立高点、宽度未解析、半高括区与采样间距同量级 | 窄峰：分裂邻近空隙，括住后读取短核区 | 检查其左右未读边缘；不将孤立高点当噪声删除 | 宽度缺失填0后当作已解析；只增加前探距离 |
| 两个高区、浅谷或未读谷，候选间有真实竞争 | 多峰：分别验证各自最关键单元，按方向批次比较 | 近邻双峰也保留独立原值候选；核查中间空隙 | 按24/32格距离强制并峰 |
| 宽趋势上原值极大点散布、尺度间残差不稳 | 宽峰叠扰动：趋势确定候选带，原值负责选目标 | 优先审计候选带中未读长隙；不让密采样污染全局噪声定义 | 把平滑最大点当正式目标；同点重读降噪 |
| 多个等高值、低对比度或量化迹象 | 平台：查询中央优先位置及未决边缘 | 保留平台内外尖点可能，按正式tie比较已读点 | 几次相等回复就断定全数组常数 |
| 最佳点在已覆盖边缘、单侧肩缺失、仍单调上升 | 边界/偏斜峰：沿缺失一侧小批前进 | 每批检查左侧目标的冗余失效风险 | 用对称峰宽外推另一侧；因N大就无限前探 |
| 低端点长空隙、模型不一致或证据不足 | 未知型：按覆盖缺口补点或承认风险后继续 | 有独立的审计额度，不依赖端点高度 | 线性插值低就删除空隙 |

## 3. 窄峰防漏：用最大空隙描述能力

固定8格的弱点是永久存在未读位置。换一个全局相位仍留下空隙，而且已完成正式实验表明相位变化会严重影响后续轨迹，不宜直接替换基线骨架。

采用嵌套补点：已有[a,b]，先查中点；若有结构变化或仍是优先待办，再拆两个子区间。8格补中点变成最大4格，再补为2格，最终只对选中的短核区逐点读取。新点属于同一缓存，后续模型复用，避免为不同策略重复付费。

若一个峰在某个明确阈值之上有连续w个位置，覆盖两端且最大相邻采样间距h≤w，则必然采到这个高值支撑中的一点。这是有条件的“碰到峰”，不是找到其原始最大值。宽度假设不成立、峰仅一个点、或覆盖未延伸到该区间时，结论不适用。

因此，防漏必须有两步：先碰到可疑结构，再核查候选短区间的原始最大值。不能把采样间距小于7直接当作误差≤3的保证：任意数组的最高点与最高已读点可以相距很远。

审计分为两路：有结构证据的空隙优先获得补点；另保留少量不依赖端点高度的空隙审计，避免“没有读到，所以没有触发，所以永远不查”的闭环。第二路只能减少遗漏，不能消除单点尖峰风险。首版用确定的最长空隙与位置分散规则，避免把随机抖动自身误当作信息增益。

## 4. 核心新机制：在不可逆右探之前完成有限核查

维护r=最右位置。若下一批将到r_new，则所有t<r_new-199的真实目标都会因R>199失去正分资格。这些位置中只有已读且被更高已读值击败的点能被直接排除；其余未读点不能靠模型删除。

前进前列出三项：

1. 哪些有证据的候选盆地即将失效，其短核区/竞争检查是否完成；
2. 哪些未知空隙将被经验放弃，是否还有顺路审计机会；
3. 核查、继续、停车三种完整路线，各需要多少Q/M/O和停车余量。

例如r_new=360，目标t≤160会超过199格。若155附近仍有待决高点，不能先走到360再决定要不要核查155。应在风险线之前完成有限核查，随后明确选择保护早峰并收尾，或者承担它仍可能是真峰的风险继续。

这不是“所有左侧空隙必须查完”的规则，否则长N无法前进。它将此前隐含的放弃变成明确决策，并禁止在已经失效后花大量查询做无法挽救的补救。即使局部核查完成，继续远探仍可能牺牲这个早期真峰；该风险不消失。

## 5. N控制容量，不决定峰型

下表只比较全长均匀网格的容量，含两端点，查询数ceil((N-1)/h)+1。不是推荐扫描全长；全扫会对早峰违反R。

| N | h=4 | h=6 | h=8 | 8格后最多剩余查询，已扣1次停车 |
|---|---:|---:|---:|---:|
| 400 | 101 | 68 | 51 | 147 |
| 650 | 164 | 110 | 83 | 115 |
| 1000 | 251 | 168 | 126 | 72 |

据此改变资源安排：短N可以更广泛补空隙；长N优先把补点集中在高风险候选带，同时留未知型审计。N=1000全长4格仅骨架就超预算，不能照搬短N方案。N=650全长6格虽可行，却不代表值得付出移动及右探代价。

不再用N≤500直接推导“短窄峰”、N>650直接推导“宽噪声峰”。初版保留已获正式成绩的起始锚点作为对照，先替换状态和动作调度，另行消融采样骨架，避免同时改动所有机制。

## 6. 预算如何防止每种专家都花一遍钱

维护共享查询池和三类待办：覆盖、候选核查、未知审计。策略只提交“需要哪一个新点以及它能解决什么分歧”，由控制器去重、排序、批量执行；策略没有独立查询循环。

停车至少预留一次真实查询，并模拟所有本批点成为新赢家后的Q和O。候选核查预算应按当前未读核区大小和路线计算，不拍脑袋固定留20次；预留不足就缩短覆盖或缩小承诺，不默默丢弃检查。

同方向、同走廊的待办合并；新高点、模型反驳或风险线事件出现就中断批次重规划。不能每发现一个候选就往返一次；O≤6通常比候选记录的内存容量更紧。

停止区分：数值上界及tie证书成立的证明停止；资源不足的停止；有限待办完成后接受残余风险的经验停止。“±3已读”“模型一致”“连续下降”均不能单独宣告全局安全。

## 7. 首版实现范围与验收

首版实现原值缓存、纯特征、全部未读空隙、多个候选记录、前沿承诺检查，以及前进/补空隙/核查/停车四类动作。不要先加入大量拟合器。候选记录全部保留，主动验证数量按预算限制；未激活不等于被排除。

```text
新回复 → 更新原值最佳与运动 → 拆分空隙 → 计算带有效性的特征
       → 各策略提出待办 → 检查即将失效的左侧候选/空隙
       → 合并同方向点集 → 审核动作及所有可能停车结果
       → 执行短批次，遇新证据立即重规划
```

预先固定反例组：8格之间的不同相位窄峰；宽峰叠窄峰；浅谷近邻双峰；早峰后远端较低峰和更高峰两种；量化平台含尖点；偏斜/边界峰；相关扰动宽峰；与当前观测完全相同但未读目标不同的成对数组。交叉N、峰位、宽度、峰高差、间距和噪声结构，不能只测单一维度。开发集与独立确认集分开，变换同源曲线不算新增独立证据。

比较基线、仅区间记录、加前沿承诺、加未知审计、完整协作五个结构版本；记录查询轨迹及触发原因。逐例报告零分原因、目标是否读到、最终d、Q/M/O/R，以及修复零分和新增零分；同时比较包含零分的总分、最低四分之一均分和非零成本。官方若只提供总分，就只报告总分变化，不能伪造逐例归因。

上述核查完成后才值得用正式测评验证一个冻结候选。当前是可实现的研究方案，尚不能宣称能适配全部隐藏样例或超过210599。
