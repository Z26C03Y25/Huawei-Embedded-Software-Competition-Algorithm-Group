## 2. N分段的+1/+4加性分解

逐份源码对照确认：`seed25`、`seed28`分别只将初始第四点24改为25、28，保留前三点0、4、12；对应分段版本只在指定N区间执行同一改动。除实验注释外，没有其他源码变化。实现见[相位变换工具](../../dev/tools/phase_candidates_20261030.py)。`initial_phase23`同时改动第三点12→11和第四点24→23，不能混入这一分解。

设父算法为B，正式固定样例集分为A：400≤N≤500，M：501≤N≤650，L：651≤N≤1000。令 `D_g(k)` 为只在分组g把第四点改成24+k时，相对B的组内总分变化。若下述稳定性条件成立，则：

```text
D_all(k) = D_A(k) + D_M(k) + D_L(k)
D_A(k)   = D_all(k) - D_M(k) - D_L(k)
```

| 第四点改动 | 全N实测差值 | M组实测差值 | L组实测差值 | A组由加性推得的差值 |
| --- | ---: | ---: | ---: | ---: |
| +1：24→25 | -5328 | -2348 | -290 | -2690 |
| +4：24→28 | -21970 | -19108 | -2851 | -11 |

这是**总分求和与互斥分组产生的条件式代数分解**，不是线性响应模型。+4不能由+1乘4预测，区间内不同N也不能互相外推。A组两项为推导值，没有独立上传A组版本；目前没有三组各自的绝对基线分、样例数量或逐例损失分解。

成立条件为：同一父源码、同一固定样例及评分规则；每例独立初始化；分段版本在组外与父算法行为相同，在组内与对应全N版本行为相同；不存在跨样例状态或资源影响。当前程序按N和读值确定伪随机状态，但还存在 `seconds()<6.8/7.5` 等墙钟截断。编译布局、运行调度或时间开销变化可能改变退火迭代数和后续轨迹，故源码条件相同不足以证明每次执行的分数完全稳定。两次读取同一作品终分只是确认判分记录，不是两次独立执行的重复性测量。

在这些条件下，+4损失主要落在M组、+1在A和M组均有明显净损失，是成立的组级结论。不能据此推断组内有几个零分、峰有多窄、噪声周期是多少、峰距是多少，或“中N天然需要某相位”。

## 3. 为什么单参数不等于单机制

[父源码](../../data/experiments/online_20261030/initial_best.cpp) 的 `features()` 约在183行、前探约在328行、候选池约在584行、精修约在904行。以下反馈链同时存在：

```text
采样位置/密度 → 观测值与原始最佳点 → 相邻关系、局部极值、半宽、残差
             → MAD、显著性、回升、状态投票 → 前探边界及停止时间
             → 精修候选/模型/额度/方向 → 新采样、伪随机状态、最终Q/M/O/R/d
```

- 局部峰是相对于已观测相邻点定义的；插一个点会拆分区间、产生或消除观测极值，未必发现了新的真实峰。原始最大值目标不能由平滑趋势最大点替代。
- 三点残差为 `r=y_b-[(1-t)y_a+t*y_c]`。光滑曲率项近似为 `-f''(b)*(b-a)*(c-b)/2`；等方差独立噪声部分的方差为 `σ²[1+(1-t)²+t²]`。当前固定除数sqrt(1.5)对应等距噪声，不能消除非等距曲率变化。加点即使落在同一光滑曲线上，也可能改变MAD与显著性。
- “最近18个残差”“最近若干斜率”按读取点数定义，密度变化会改变所覆盖的物理区间；`f.left`、半宽和极值簇也随布局改变。噪声与真实细峰的区分依赖假设，不能只靠一个标量完成。
- `features()`还更新状态、投票和访问计数；调用次数属于动态过程。伪随机状态又由真实回复混入。因此附加查询、额外特征调用或路径变化不只是增加一个Q。
- 查询、移动、反转、历史最右点、停车余量是不同代价。提前停下可能省成本，也可能让停车或命峰失效；回程不能修复已发生的真实冗余。总分差不能唯一分解成这些来源。

## 4. 先验证特征能力，再选择结构性算法

下一步先固定特征定义与预期用途，用可解释的有限反例检验能力，不依据本地均分连续调整阈值。完整曲线在离线检查中只用于揭示遗漏和错误置信，不用于宣称已重建官方分布。

| 检查维度 | 需要明确的能力与验收方式 |
| --- | --- |
| 证据与目标分层 | 分开记录原始最佳点、稳健趋势、竞争峰证据及未观测区间；任何“平滑”都不能删除原始值。对同一观测历史允许多个兼容峰位置，不给不可识别状态虚构确定类别。 |
| 采样布局 | 同一已知曲线以规则、相位偏移、插中点、稀疏间隔读取；记录物理跨度、间距和覆盖率。精确常数/直线/二次曲线的插点不应无理由制造高噪声；真实高频扰动应保留不确定性。 |
| 多维峰形 | 分别检验窄峰、宽峰、非对称峰、尖点、肩峰、浅谷双峰、近等高峰、量化平台和孤立原始高点；检查定位区间是否覆盖真实原始最大值，以及错误置信发生在哪个条件。 |
| 噪声结构 | 独立扰动、相关扰动、周期纹波、随位置变强的扰动与平滑曲率分别检查；不能把可预测曲率与噪声混为一类，也不能把细峰一概去噪。保留无法区分的成对反例。 |
| 状态与纯度 | 对固定观测集重复提取，静态特征应幂等；状态转移应有明确时钟，原则上每次真实新读取只更新一次。同一观测集按不同到达顺序比较静态特征，运动历史另行保留。记录触发条件与行动前后状态，避免一次诊断调用改变决策。 |
| 不变性与边界 | 不溢出且不引入量化的正仿射值变换应保留原始排序；低幅值绝对阈值造成的例外须写明。镜像应正确交换峰形左右信息，但起点为0且R有方向性，不能要求运动分数镜像不变。N和峰宽缩放时检查物理尺度，不强求有限预算下轨迹等价。 |
| 反例与止损能力 | 必须保留早峰后更高峰、背景后晚峰、两低端点间窄高点、平台中更早尖点、边界峰与近似同观测异目标对。逐条说明可识别、应继续查、应承认不确定的条件；协议与真实停车检查保持严格。 |

通过上述检查后，再选择**一个**结构性算法：说明它使用哪些可验证特征，在哪种未决状态采取哪种行动，何时预算允许、何时停止，并在设计前固定失败条件与反例集。先验证该机制能否改变预定的错误决策及是否引入新错误，再做冻结版本的独立确认与正式评测。若特征仍不能区分关键反例，应先修正表示或承认信息边界，不继续扫描相位、N边界和噪声常数。

目前23轮只足以保护210599基线、定位敏感分组和否定这些具体改法的净收益；尚不足以选定下一份结构性求解器。
