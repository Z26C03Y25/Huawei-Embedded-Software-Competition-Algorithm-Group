## 这次分析改变了什么

当前框架把同一批采样同时用于原始最佳点、噪声、峰宽、极值簇、状态投票和停止判断。改变采样位置后，这些量一起变化；仅修改一个参数也不等于只测试了一个机制。新的表示必须保存特征的采样来源、物理跨度、有效性和未决区间。

建议状态分成四层：

| 层 | 保存内容 | 作用 |
| --- | --- | --- |
| 原始观测 | 每个已读整数值、原始最佳点和中央平局顺序 | 决定实际停车候选，不能被平滑值替换 |
| 多尺度证据 | 斜率、曲率、宽度括区、残差、量化迹象及各自支持点 | 描述哪些峰形假设有证据，哪些仍未知 |
| 区间与候选盆地 | 已读区间、未读空隙、候选峰区间、竞争关系、删失边界 | 保留其他可能主峰，选择下一处有辨别力的查询 |
| 运动与资源 | Q、位置、方向、O、移动量、最右点、停车余量 | 决定完整动作加停车是否可行，并记录前探的不可逆风险 |

特征提取应是纯函数；状态转移每次新观测发生一次；运动历史与静态空间特征分别保存。诊断调用、重复计算和同点停车重读不能无意改变形状投票。

## 三个可复现的机制检查

检查脚本为 [audit_feature_geometry.py](../../dev/tools/audit_feature_geometry.py)，结果为 [mechanism_checks.json](../../data/experiments/feature_analysis_20261030/mechanism_checks.json)。它不运行求解器、不联网、不上传，也不优化本地得分。

```powershell
& ./python/runtime/python.exe -X utf8 dev/tools/audit_feature_geometry.py
```

1. **采样几何混入噪声估计。** 对同一条精确、无噪声二次曲线，均匀8格采样下原MAD噪声为0；指定混合间距布局下变为19.368605。该数来自曲率和间距，不是新产生了观测噪声。曲率校正可通过这个性质检查，但此前第17轮校正候选正式降100分，所以不能据此宣称它会提分。
2. **观测相同不等于主峰相同。** N=400，查询0、8、…、184时，两条数组回复完全相同；其中一条目标96，另一条在未读143处存在更高值，目标143。任何只看这段历史的特征都无法区分它们。未读空隙必须作为未知保留，不能因端点低而赋予零风险。
3. **相邻点不等于相同噪声证据。** 在明确假设的AR(1)相关模型中，同样的真实噪声幅度，点距1/8时，理论残差标准差经独立噪声公式归一后的比例约0.185/0.512。这不是有限样本MAD必然取到的数，也不是对比赛噪声的估计；它说明必须携带实际点距与相关性适用条件。

## 如何由特征导出动作

- 峰宽尚未解析、采样间隙与可能峰宽同量级：优先补空隙，不能宣布窄峰已经覆盖。
- 多个候选盆地的原始高度或模型支持接近：查询能区分它们的位置，保留竞争关系，不先把近峰合并掉。
- 宽峰叠加扰动：平滑趋势只决定待查区域，原始极值的位置风险要单独处理。
- 平台或量化迹象：处理等高值中央规则及边界删失，不把低对比度等同于全数组恒定。
- 前探将使左侧候选位置的R超过199：先明确会放弃哪些仍可信的目标，再决定补证据、前进或停车；未知真实目标下不存在通用的安全保证。

N只确定坐标尺度、覆盖容量和资源约束，不替代峰形识别。不同N可分配不同覆盖/验证容量，但不能先假定某个长度就是某类曲线。

## 进入实现前的条件

先验收同一曲线在插点、错相和不等间距布局下的特征行为；检查静态提取幂等性、缺失标记、值平移/合法缩放、相关扰动、窄峰/浅谷双峰/宽平台等反例。再实现一个能根据未决证据选择“前进、补空隙、验证候选、停车”的控制器。首先验证动作是否消除了预先指定的错误置信，再用未消费的独立确认集和少量正式评测验证收益。
