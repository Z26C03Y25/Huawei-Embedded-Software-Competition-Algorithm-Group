# 冗余窗口、停车可行性与越线决策

2026-11-01。正式初始分212686，后续反馈见[当天实验](../../data/experiments/blackbox_20261101/README.md)。用户要求使用30次线上机会；后续不复测相同代码，未决作品只恢复原ID查分。

## 目标窗口与停车窗口不同

记最右历史位置为r、未知真实目标为t、最终停车为p。正分要求：

```text
r-t <=199   ⇒ t >= r-199
abs(p-t)<=3 ⇒ p >= r-202 是可能正分的必要条件
```

因此，已读原值最高点b若严格小于r-202，停车b对任何真实数组都不可能拿正分。等号不能排除：当b=r-202、t=r-199时，d=3、R=199仍可正分。

在搜索前缀完全相同的前提下，只对这种必零末态改停在窗口内合法候选，不会破坏原来可正分的停车。候选仍须通过真实查询、转向及预算检查；候选已读原值可能低于窗口外旧最大值，这不是改变赛题目标，而是在旧目标假设已经无法得分时，为未读的更高真峰选择可能距其3格以内的位置。

如果真实目标本来就是窗口外旧峰，越过之后任何停车都不能恢复这例；新规则并不解决已经发生的真实R违规。

`viability_parking_v2`保留212686全部搜索前缀，只改变上述末态；恢复时强制真实查询一个已读候选，因此本地检查可以从最后一次查询之前的轨迹独立验证：旧赢家必零、新停车点已在缓存、最右位置未增、停车点在可行窗口内。原26例协议、Q/O和真实停车检查保留；旧赢家停车检查只增加这个有证明的例外。

[边界检查](../../dev/tools/check_parking_feasibility.py)验证75个停车边界位置，并提供合法正分反例。它是评分几何验证，不是本地性能筛选。该候选正式得分212686，尚无实际总分收益，不能声称恢复了正式零分样例。

## 越线之前必须明确押注

即使读到连续回升，也不能证明未来峰高于旧峰；若旧峰仍是真目标，越过其199格后返回仍是零分。固定种子随机点、凸包和外推也不能消除这个信息限制。

`early_rebound_pilot`是单独的风险实验：对长数组前部、具有一定观测宽度且中等噪声的候选，先观察到旧点+176附近；只有三组中位数持续上升、外推能够超过旧值，才逐段放行，最多到旧点+399。它可以牺牲旧峰的正分机会，不是硬安全保证。查询、转向和停车余量仍逐次审核。

另一个独立实验`marginal_signal_tail_guard`针对原本不显著但已出现明显下降的噪声曲线：只改变前探边界，不同时降低精修模型的置信要求。两种策略分别评测，不能假定组合增益相加。

## 总分差也可能是共同搜索成本

用户提出：约2万分差，可能接近100个样例各多付200分冗余，而非少数零分。这个解释与总分观测相容，但总分本身无法辨识两者。严格地说，正分样例的R最多199；R达到200会触发硬约束，而不是仅扣200分。

在目标、最终停车、转向结构和精搜轨迹相同的条件下，从峰右侧额外前探Δ格再返回，会增加约2Δ移动及Δ冗余，还增加查询数。因此成本差约为`3Δ+ΔQ`，而非只有Δ。按102例估算，每例平均额外64格即可产生约19584分差（尚未计查询）。这只是量级分析，不是对官方样例轨迹的推断。

现有基线的中长N峰后探测距离通常为80..144格；短N为16..32格，过中点后收至16。`halve_postpeak_scout`单独将这段预算减半、下限保留16，不同时改变网格、回升判断或精搜。若成功，说明节约共同成本值得进一步按N及形态分组；若失败，需要区分漏掉后峰、模型信息不足和噪声分类变化，不能只凭总分指定其中一种原因。

归属更正：用户明确指出02:04:15的146180分属于其手动实验。此前自动查分将这一较晚出现的同名新作品误归属给减半候选；该成绩现已剔除，不进入拟合，不支持“减半失败”的结论。减半候选的实际投递和成绩未确认，原任务停止关联该手工作品，也不重复上传。已保留原始观察和撤回记录。

下一步应比较追加探测的期望收益与实际代价：多探Δ格至少承担相应移动/查询成本，只有它发现更高峰或避免错误停车的概率乘以可挽回分数足够大，才值得继续。这里的概率只能用不同机制候选的官方总分间接校准，不能从一次总分倒推出逐例标签。最高正式源码在新候选确认改善前保持原样。

## 已确认的条件止损收益

[216233版](../../data/versions/main_online_216233.cpp)相对212686提高3547。新增条件是已观察到左右两侧半高点、近期至少三次显著下降且没有上升或回升；满足时将原scout减半并保留16格下限。原显著性、竞争峰、下降幅度、真实查询预算、转向与停车审核仍然执行。它依赖峰形判断，不证明未读区域不存在更高峰。

仅在N>650启用这条规则，直接测得213161，即贡献475；N<=650合计贡献由互斥策略差值推断为3072。两组均为正，因此没有仅保留长数组规则。这个分组推断不能反演逐例得分。

[216258版](../../data/versions/main_online_216258.cpp)在相同触发条件下，将尾探预算进一步限定为：

```text
min(max(16, originalScout/2), max(16, ceil(1.5*observedRightHalfWidth)))
```

这使用已经读到的右侧半高宽，减少左侧宽度或N导致的多余尾探；正式增加25分，累计增加3572。不能据此断言全部增益都是R或M：提前停止还会改变噪声估计及后续精搜路径。

其他维度的独立反馈：起始0..24连续读点相对212686下降4114；216233上短数组补区间中点下降119；216258上长数组宽缓段16格步长下降41，长数组分层随机网格下降5040。下降的方案均未替换最高版；这些总分不等于对隐藏曲线类型的直接标签。全部候选及后续结果保留在[当天记录](../../data/experiments/blackbox_20261101/README.md)。
