# 多维曲线特征：可观测性、采样几何与查询动作

日期：2026-10-30。本文只分析现有代码、赛题和已完成的23轮正式结果，不修改求解器，不设计新的参数扫描，不联网、不提交。

依据：[当前求解器](../../main.cpp)、[评分定义](../concepts/problem-and-score.md)、[23轮正式记录](../../data/experiments/online_20261030/results.json)、[逐轮说明](../../data/experiments/online_20261030/README.md)。当前正式最高分仍为210599，源码SHA256为`55f74d74926c235485d16ddb31e5e073a4fbde7ad0b71159410fa80429ad23ed`。

## 1. 先明确算法实际看得到什么

运行时信息是查询历史`H={(z_j,y_j)}_{j=1..q}`、N、自己的程序状态和剩余预算。数组值固定，同一位置重复查询不产生新的独立噪声样本。历史顺序z_j决定真实移动和转向；按位置排序的唯一已观测点`x_0<...<x_{m-1}`用于空间特征。二者不能混用：q可以大于m，空间相邻不等于最近查询。

记当前已观测原始最佳位置为b，值为y_b；实际电机位置为p；曾到最右位置为r；`C=max(y_i)-min(y_i)`为观测对比度。b按正式中央平局规则在已观测点中选取。真实全局目标t仍未知，除非已有完整证明。

每个特征应同时带三个信息，而非仅给一个浮点值：

1. **数值或区间**，包括原始单位与尺度归一值。
2. **有效性和删失标记**：例如右半高交点尚未观察到，应为缺失/右删失，不能编码为宽度0。
3. **采样证据**：使用哪些点、最大间隔、覆盖的实际位置跨度、点的来源。需要区分粗搜骨架点、额外中点、模型验证点、普通精修点和停车重读。

“由查询数据算出来”不等于“它正确描述完整曲线”。观测峰数、观测噪声、拟合宽度都可能带有强烈的策略选择偏差。

## 3. N、相对位置和尺度：保留两套坐标

横轴既要有原始格数，也要有`u=x/(N-1)`。归一坐标适合比较不同N的形状；原始坐标负责物理移动代价、停车误差≤3、冗余≤199等赛题约束。只保留`x/N`会丢失这些不随N同比缩放的硬条件。

竖轴可以同时保留原始值、观测对比度C、局部稳健尺度和归一相对高度`a_i=(y_i-min(y))/C`。C=0、IQR=0、有效样本太少必须带有效性标记，不能靠一个任意小常数把未知变成很大的信噪比。原始1个整数单位可能决定全局目标及平局，因此尺度归一不能替代原始值通道。

N用于决定容量和边界，不应直接编码“这是窄峰/单峰/可以早停”。此前501/650等分段有正式经验，但它们不是题面给定的曲线类别标签。

只作容量算术，含两端点的全长均匀8格网格查询数为`ceil((N-1)/8)+1`：N=400/650/1000时分别51/83/126。总预算199另留1次停车后，理论剩余147/115/72次。这不是实际路线建议：若真实峰较早，扫完整个N可能先使R超过199，之后回退不能修复；额外初始化、错相、审计和精修也会改变实际计数。

## 4. 峰宽与曲率必须带“已解析到什么尺度”

### 4.1 半高宽是局部假设量，不是原始数组真值

选定观测背景B后，可用`H=y_b-(y_b-B)/2`定义半高阈值。在b左右寻找已观测的上/下阈值邻点，分别保存穿越括区及其跨度。只有在该侧局部峰形连贯、没有未决竞争峰、背景定义合理时，才可将插值穿越位置解释为峰宽估计。

以下情况必须显式保留：

- 一侧未见下降到半高：该侧删失，不是半宽0。
- 不同背景B会显著改变宽度：背景不确定。
- 多个高区间由未读间隔连接：不能把它们自动合并为宽平台。
- 半宽与最大采样间隔同量级：峰形尚未解析，不能据拟合宽度决定已经安全覆盖窄峰。

当前`halfLeft/halfRight`初始化为0，并由已读低于半高点的位置给出距离；它们没有完整的缺失/删失类型，也不是精确半高穿越。当前`left/right`还可能横跨多个高值区，需要与单峰宽度区分。

### 4.2 非均匀网格上的可比曲率

对`a=x_{i-1}, x=x_i, b=x_{i+1}`，设`h_L=x-a, h_R=b-x`：

```text
s_L = (y_x-y_a)/h_L
s_R = (y_b-y_x)/h_R
kappa = 2*(s_R-s_L)/(h_L+h_R)
```

κ的单位是“值/格²”；可再保存`κ*(N-1)²/C`用于跨尺度比较。当前`f.curvature`是最右侧两个割线斜率之差，未除以间距和，而且位置通常在前探前沿；它不能直接作为当前最佳峰附近的二阶曲率。

当前`f.rises/f.falls`也使用按x排序的空间尾部：点数足够时，以最右6个已观测点为右端点，分别与其左侧相邻已观测点计算差分，因此除这6点外还会用到其左边的一个邻点；点数不足时少算。它们不是最近6次查询的上升/下降次数。向左精修后，即使这些点是刚查到的，也不一定进入这个最右空间窗口。

在局部二次、单一峰、曲率稳定等假设下，可用`宽度尺度≈sqrt(C/|κ|)`作查询尺度提示。但该式不是峰宽证书；κ在噪声下接近0、符号不稳或随尺度变化时应输出无效/不稳定，而不是无限宽或任意截断值。

## 5. 噪声特征有采样内生性

当前代码用相邻已观测三点的线性插值残差：

```text
t = h_L/(h_L+h_R)
r = y_x - [(1-t)*y_a+t*y_b]
noise = max(MAD(全体r), MAD(最右侧至多18个空间残差r)) / 1.2247448714
```

这里先按x递增遍历`f.x`生成残差，`local=residual.end()-18 ... residual.end()`取的是残差中心位置最靠右的至多18项，**不是最近18次查询，也不是最右18个原始值**。每项依赖三个空间邻点，18项残差的联合支持最多涉及20个已观测点。查询时间窗需要按历史z_j另行定义，不能用这个local向量代替。

对局部平滑信号f，二阶展开给出：

```text
r_signal ≈ -0.5*f''(x)*h_L*h_R
```

因此从8/8间距变成4/4间距，二次曲率对残差的贡献幅度变为原来的1/4；混合不同间距会改变残差分布。不能进一步断言“MAD一定变为1/4”：恒定曲率、等间距下残差可能为常量，MAD本来就为0；混合几何和变化曲率才会形成更复杂的变化。

这个“最右侧18项”也不是固定物理窗口。若在最右支撑区域内加密，它覆盖的位置跨度可能缩短、成员及邻接关系也可能变化；原先的全局/局部最大值比较随之改变。但在足够靠左、未触及该尾部三点支撑的区域补细点，local成员和数值可以完全不变。若新点改变了尾部某个中心的左/右邻点，即使残差中心成员未变，该项残差仍可能改变。更左补点也可能新增或改变其附近的全局残差，从而通过全局MAD影响最终noise；这些影响都不能仅从“刚增加了查询”推出。

应同时记录窗口的排序依据（空间/查询时间）、点数、原始跨度和归一跨度，不能把三类窗口视为同一种特征。降序精修中刚查询到的左侧点，不能被想当然地解释为进入了当前local或rises/falls窗口。

如果将残差中的噪声看成独立、等方差测量误差，则其方差因子为`1+(1-t)²+t²`，仅当`t=1/2`时等于1.5。若空间噪声相关，正确形式是`Var(r_noise)=wᵀΣw`，`w=(-(1-t),1,-t)`；不能继续用独立噪声分母自称获得真实σ。

已有的骨架残差与曲率归一实验分别回答了“额外中点是否改变noise几何”和“如何补偿不等间距曲率/方差”两个问题。它们仍依赖形状与噪声假设，而且正式结果未带来提升，不能把此前加密退化全部归因于MAD。加密还会改变原始最佳点、对比度、斜率计数、观测峰数、模型输入、粗搜剩余额度和后续轨迹。

特征设计上需要保留：原始残差摘要、所用三点间距乘积/比例分布、骨架与补点的来源比例、窗口物理跨度，以及“局部恒曲率/平稳/独立噪声假设是否得到支持”的状态。后者是模型适用性判断，不是由稀疏数据证明噪声生成机制。

### 5.1 量化和相关性不能用一个noise数混为一谈

观测相等值率、相邻正差分分布、GCD、局部唯一值个数可以反映量化迹象，但未读级别会使观测GCD偏大；平坦信号、传感器饱和、取整和真实平台也可能产生相同现象。

空间相关应按实际距离分组估计，而不是把“相邻两个已读点”统一当作固定滞后。非均匀采样的相邻点可能相距1、4、8、几十格，直接算一个相邻残差相关系数会混合不同物理尺度。残差还共享原始观测点，即使原始误差独立，相邻插值残差也未必独立。

相关性或长平台证据只能影响下一次空间查询的距离和方向；重复读取固定数组同一点不会独立降噪，平滑后的峰也不能替代原始整数最大值。

## 6. 多峰、空隙和混叠要按“区间”表示

### 6.1 观测峰与真实峰分开

可在排序观测点上计算局部峰集合P_obs，保存峰间距离、相对高度差`(y_b-y_p)/C`、已观察谷深、谷区最大间隔、两峰附近是否各有下降侧。分离程度可同时表示为原始格数、N归一距离和相对峰宽比；宽度未知时第三项应缺失。

P_obs不是完整曲线峰集合。当前代码将距离24以内的若干峰代表合并，模型早收尾的竞争检查又忽略距b≤32的另一个峰。这些是策略动作，不是“近于24/32的峰属于同一真峰”的证据。特征层应保存原始候选与分离证据，再由决策层决定查询；不能先合并再把合并结果作为没有竞争的证明。

### 6.2 未读间隔是可精确知道的，内部最大值不是

每个相邻已观测点间的未读区间应至少描述：长度、端点原始值/相对高度、可用的两侧斜率、所在位置、到当前电机和最佳点的距离、所属候选竞争区、下一查询是否顺路。首尾未覆盖区也必须保留，不能只统计两个已读端点之间的空隙。

这些量可以用于选择能够区分候选形状的查询。若确有已知`|f''|≤L`，才可用`max(端点值)+L*h²/8`作为区间内最大值的保守上界。题目未给该上界；由样本估出的L只是模型量，不能将其作为排除隐藏尖峰的证明。

模8采样直方图、不同余数覆盖率、最大未读连段能显示固定网格的盲区。它们不等于真实窄峰漏检概率。改变起始相位不仅改变余数，还改变初始区间跨度、回复值、最佳点和后续分支，不能仅凭一个总分把结果解释为某个固定相位“更容易命中”。

在已知峰的有效支撑为连续w个位置、并且边界和最大空隙满足相应覆盖条件时，采样最大间距≤w可以保证碰到支撑中的某点；仍不等于找到支撑内原始最大值。对任意未读位置都可能藏有独立尖峰的数组，有限查询无法提供这样的支撑假设。

## 7. 成本、可观测冗余代理和停止证据

Q、M、O、p、r可以精确知道。`r-b`是相对观测最佳点的前探距离，`|p-b|`是回到观测最佳点的距离，它们不是正式真实冗余R和最终误差d。真实目标t未知时，不能把本地完整数组算出的R/d偷偷带回运行时决策。

一条具体计划若假定b不变，可以精确模拟新增查询、移动、转向和真实停车；若新点成为最佳点，停车路线和后续分支会改变，需要同时考虑这个结果。将最右位置从r推进到r+Δ，真实冗余增量介于0和Δ之间，取决于未知t，不能总按Δ或0计为确定成本。

新增查询可能节省未来成本，也可能引入错误停止。有限插值场景的平均分没有自动成为已校准的成功概率；“六个场景都赞成停车”只表示这六个场景没有表达更高未读峰。

可以作为强停止证据的条件应与启发式判断分开，例如读到数值上界VMAX后，对所有按正式平局规则可能更优的位置完成排除。当前`certificate()`检查的是这类特例。局部±3已读、两个拟合顶点接近或原始最佳点位于验证窗口内部，均不构成任意数组的全局证明。

## 9. 建议的运行时特征向量及缺失掩码

以下是分析用的特征规格，不是新求解器或参数表。向量应保留原始单位、归一单位和来源分组，避免把所有维度压成一个“显著性”布尔值：

```text
z_observed = (
  N, 3/(N-1), 199/(N-1),
  q, M, O, remaining_reads, remaining_turns, parking_cost_to_b,
  u_b, u_p, u_r, r-b, p-b, distances_to_boundaries,
  observed_contrast, local_IQR, raw_top_value_gap, observed_quantization_summary,
  unique_sample_count, gap_distribution, local_physical_spans,
  max_unread_run, uncovered_prefix_suffix, residue_histogram_8,
  normalized_slopes_by_scale, normalized_local_curvatures,
  left_right_crossing_brackets, width_asymmetry, width_resolution_ratio,
  raw_residual_summary, skeleton_residual_summary, spacing_product_distribution,
  residual_spatial_window_spans, separately_labeled_query_time_windows,
  distance_binned_correlation, spatial_drift_summary,
  observed_peak_count, competitor_separations, relative_heights, observed_valley_depths,

  point_provenance_counts, action_history,

```

其中`width_resolution_ratio`可以描述估计峰宽与邻近最大间隔的比例，但峰宽未解析时必须缺失。`distance_binned_correlation`、`skeleton_residual_summary`等若证据不足，也应缺失；不能统一填0后让决策器误读成“无噪声、无相关、无竞争”。

### 9.1 不可观测项的明确列表

以下只可用完整本地曲线作为oracle评估/诊断，默认运行时不可得：

1. 真实全局目标`t*`、全局最大值`y*`、所有最大值位置与最终平局目标。
2. 真实R、真实d，以及当前已观测最佳点到真实目标的误差。
3. 未读区间内的最大值、最大值位置、隐藏尖峰高度/宽度及数量。
4. 完整曲线的真实峰集合、最近竞争峰、全局峰间分离和真实谷深。
5. 未观察一侧的真半高交点、真实背景与完整峰宽；已读范围之外的边界走势。
6. 未采样位置上的真曲率界、真Lipschitz界及可保证的插值误差界。
7. 真实传感器噪声σ、真实噪声过程/相关长度、物理量化器步长；固定数组的样本本身不提供生成机制标签。
8. 某未执行查询必定带来的分数收益、停止后的成功概率、另一条策略在官方逐例上的反事实得分。
9. 官方102条曲线各自的N、曲线类型分布、哪些例子触发了分支以及各例分数分解。

oracle指标应与z_observed在数据结构和命名上分开。可以用oracle验证“一个观测特征在什么条件下可靠”，不能用oracle给运行时选点，也不能把由完整曲线计算的峰宽/噪声标签冒充稀疏观测特征。

## 10. 此阶段应产出的分析证据

下一步应先回答“特征是否描述了它声称描述的量”，再决定算法：在同一完整本地曲线上保留不同采样几何的观测历史，分别检查特征漂移、缺失率和相对oracle的误差；完整曲线只进入评估端。比较时记录相同物理窗口与相同点数窗口两种口径，并按采样来源区分骨架与追加点。

还要将“特征数值变了”和“决策分支变了”分开记录。代码中的`features()`目前会更新状态机、投票、计数；将它额外调用一次作分析并非纯读操作。未来若做离线诊断，应读取已有历史或使用明确无副作用的计算，不在此阶段给运行中的算法添加新的features调用。

本文件仅提出特征定义、有效性条件和可证伪的查询用途。它不再追加步长、相位、半径或阈值实验，不把23轮聚合分数解释为隐藏样例画像，也不声称已经得到更高分策略。
