# 区间证据与运动预算控制器

2026-10-30。本文是供评审的算法设计，没有实现新求解器、修改最高分源码或提交作品。阅读背景见[证据边界](evidence_limits_20261030.md)、[11维特征](feature_dimensions_20261030.md)及[本轮入口](README.md)。

建议将控制对象从“一个最佳点及其精修池”改成“尚未解决的区间、竞争盆地和一条可执行方向批次”。原始最佳点仍必须维护，但它只负责原值排序和停车，不能独自代表搜索是否完成。这个方案的主要价值应通过减少遗漏和不可逆右探来验证，不能仅以多生成了几个特征作为成功。

## 1. 先确定不能承诺的部分

真实目标t是原始整数数组的最大值位置；同值时最小化`(abs(2*i-(N-1)), i)`。初始位置为0，最终位置为最后一次真实查询的位置。

```text
Q = 实际查询数
M = 全部真实位移绝对值之和
O = 非零移动方向改变次数
r = 历史查询到达的最右位置
R = max(0, r-t)
d = abs(最终位置-t)

Q≤199、O≤6、R≤199、d≤3等条件满足时：
score = max(0, 3000-200*d-Q-M-O-R)
否则该例为0。
```

Q、O和停车预留可以按动作严格控制。真实t未知时，R和d一般只能做风险管理。若继续右探使一个仍可能为真的左峰超出199格，再返回也无法恢复该假设下的分数。删除候选表里的左峰不会改变这个事实。

少于200次查询不能对任意400～1000点数组保证全局命中。两条数组可以在全部已读点完全相同，而在一个未读点具有不同的真正最高值。因此，任何平滑、拟合、多尺度一致或有限场景一致都不能把一个未读区间证明为安全。重复读取固定数组同一点也不会获得新的独立降噪样本。

## 2. 控制器保存什么

所有空间特征是已读缓存的纯函数。一次新观测只触发一次状态更新；诊断、重复计算和最终同点重读不额外投票。每项特征保存支持下标、实际物理跨度、有效性和删失原因，不能只保存一个数。

| 对象 | 最小字段 | 更新或用途 |
|---|---|---|
| 原始缓存 | `value[x]`、已读集合、原始最佳点b及值 | 原始值永不平滑覆盖；每次新读取后按正式tie规则更新b |
| 运动账本 | `p,dir,Q,M,O,r,deadline` | 只由真实输出查询更新 |
| 基本空隙 | 相邻已读点`[a,b]`、内部未读数、最大缺口、端点原值、是否审计 | 一次插点将一个空隙拆成两个；未读整数点始终保留为未知 |
| 多尺度骨架 | 各物理尺度的趋势方向、肩部括区、曲率范围、残差及支持点 | 提供结构证据和选点方向，不决定最终目标 |
| 盆地记录 | 区间`[L,U]`、原始最高点、左右肩状态、竞争者、未读关键单元 | 保存多个候选及其不同的不确定来源 |
| 证据待办 | 哪个空隙/盆地尚需何种观测、优先级、有限查询额度 | 防止模型收尾或经济止损跳过尚未履行的检查 |
| 风险记录 | 被本次前进暴露的左侧候选、边界来源、放弃原因 | 区分证明排除、观测击败和经验放弃 |

盆地可由局部极值和两侧趋势建立，但不按固定24格距离直接合并。存在可解析的谷时保留两个盆地；谷尚未采到时标记为“未分离竞争”，而非默认一个峰。原始孤立高点即使没有平滑骨架支持，也单独建立原值声明，不能作为毛刺丢弃。

工作集合初步只给最多3个盆地分配主动验证额度，另保留右侧未覆盖区域。其余记录进入归档待办，原始缓存不删除。超过容量应显式标记拥挤和未决竞争；“未激活”不表示已经排除。3只是待验证的计算/资源上限，不是赛题最多三个峰的假设。

## 3. 原值与多尺度骨架如何分工

骨架使用若干物理跨度上的局部趋势或稳健局部模型。窗口按下标距离定义，不能让一次密集精修生成的大量点把全局特征的权重淹没。对不等间距观测，要携带实际间距并处理曲率对残差的贡献；残差MAD不直接命名为已知噪声上界。

骨架回答的是：这里是否有持续上升、下降、宽肩、未解析谷或平台边缘。原始通道回答的是：目前真正读到的最高值在哪里。两条通道发生分歧时，分歧本身产生一个验证任务。

例如，平滑峰在250附近，但原始高点在267，不把267降权后停车250；需要围绕267保留独立原值候选。反过来，原始最高点在252且±3已经读完，也不能排除未读267存在更高峰。这正是先前全N后缀止损反例暴露的边界。

多模型可以提供建议位置，但需附带三项说明：使用哪些点、哪些新读取能反驳模型、模型不能描述哪些未读结构。几个共享样本的模型一致不是独立证据，更不是可信后验。

## 4. 一条观测怎样更新状态

1. 先按原始值和tie更新b，再拆分所在空隙；运动历史单独入账。
2. 重新计算受影响的局部骨架。改变采样间距时，重新核查特征适用性，不能把数值变化全部解释为曲线变化。
3. 更新盆地的肩部、原始极值、竞争关系及边界删失。新高点可能产生新盆地，原有竞争盆地不会仅因b改变就消失。
4. 若新点与先前模型预测明显不符，撤销相关的模型收尾资格，创建补查任务；不撤销已经发生的位移或右探。
5. 检查下一次前进会使哪些左侧候选的可得分条件永久失效。先产生风险事件，再决定继续、补证据或收尾。
6. 清理已经真实完成的待办。未读点不能因为当前插值较低而被标成已解决。

盆地可以“局部验证完成”，但这个标签只表示约定的小区间或检查任务完成，并不表示全局最优已证明。所有标签都要记录适用区域。

## 5. 动作库及其所需证据

一次动作是1～若干个新点组成的小批次，连同一个合法停车方案。动作生成与动作执行分开；批次执行中若出现新原始最佳点、模型被反驳或资源事件，就在合法位置停止旧计划并重规划。

| 动作 | 需要的已读证据 | 查询位置与预期解除的问题 |
|---|---|---|
| 继续骨架覆盖 | 尚未包围峰、前方趋势未决，或没有足够信息形成盆地 | 沿当前方向取得少量新骨架点；区分继续上升与出现肩部 |
| 补空隙 | 间距与峰宽括区同量级、模型分歧、边缘突变，或被选中的未知审计单元 | 二分空隙；必要时补齐小单元，降低相位漏峰风险 |
| 盆地内核查 | 一个盆地已出现两侧证据，但原始峰位未解析 | 在预测分歧位置、原始高点邻域或未读边缘读取；最后仍按原始值比较 |
| 比较竞争盆地 | 两个候选的原始高度或模型支持不足以区分 | 在同一方向批次内分别验证关键单元，避免先把其中一个合并掉 |
| 平台/tie检查 | 多个相同原始最高值、量化迹象或中央位置尚未读 | 查询中央优先位置及必要边缘；不能由少量等值回复推出全数组恒定 |
| 停车 | 证书成立、预算/时间不足，或约定验证已完成且不再继续承担探索成本 | 真正查询b并DONE，不能以缓存访问代替移动 |

对“端点都低”的区间也保留有限审计入口。否则任何多盆地算法仍会重复低估隐藏尖点的问题。审计并不声称已经排除整段任意尖峰：查询中点只能消除该点的不确定性，只有内部整数点全部读完才能在该单元内做原值穷尽比较。

## 6. 预算与有限方向批次

不预设一次粗搜后固定两轮精修。控制器维护当前方向和待办队列，倾向把同方向、同一走廊内的查询合成一个批次，减少为了单个候选反复横穿。允许转向由完整路线审核决定，不因“信息价值高”绕过O上限。

给定点集最小点L、最大点U、当前位置p及拟停车w，两种单调批次的移动成本为：

```text
升序：abs(p-L) + (U-L) + abs(U-w)
降序：abs(p-U) + (U-L) + abs(L-w)
```

新回复可能改变最佳点，所以停车候选至少包含当前b及所有本批新点。对这些可能结果检查查询和转向预算，不能只按旧b的停车路线审核。保守条件是执行查询后仍保留一次真实停车读取，并确认最坏停车结果也不超过6次反向。实际方向按非零位移模拟；同点读不增加方向变化。

动作成本可用`ΔQ + ΔM + ΔO + Δr`比较，其中ΔM、ΔO包括停车。Δr是额外冗余成本的保守代理，不是真实R：对固定目标，额外R不超过Δr，但跨过199会让该目标假设直接零分。涉及d或硬阈值时必须比较完整评分，不能只使用线性的微小成本近似。

查询预算分为共享池与有限待办额度，而非按峰的标签固定给满。至少保留停车额度；给骨架覆盖、竞争验证和未知间隙审计分别记账，未使用额度可回流。具体比例需要验证，本文不把某个任意比例当作已确定算法。一个待办消耗完额度仍未解决，应标记未决，而非自动宣告模型正确。

## 7. 如何选择动作，不引入假后验

第一版建议使用可审计的优先级和成本规则，而不是为隐藏峰生成未经校准的概率：

1. 先处理协议、时间和停车硬约束；证书成立则停车。
2. 若即将越过受保护左盆地的冗余危险线，先在“完成该盆地关键待办、继续并承担放弃风险、停车”之间作明确选择。
3. 在当前方向上优先完成已经承诺的竞争验证和小单元待办；有多个可行动作时，比较解除相同待办所需的完整路径成本。
4. 对尚未包围的区域分配骨架覆盖；对已包围盆地分配原值核查。局部模型分歧和最大漏隙决定检查位置，不能由原始最佳点的固定半径独占全部额度。
5. 仍有审计额度时，保留少量不依赖高端点的空隙审计。没有足够资源继续履行待办时，停车并记录尚未解决的风险。

可选的结构场景只用于反驳一个动作或比较敏感性。例如分别放入平滑峰、近邻双峰、低端点间隐藏高点、量化平台。场景必须保留全部真实回复，场景数量不是概率权重，复制一个场景不能增加它的证据。若不同场景建议不同动作，结果应记为决策未决，随后需要查询或接受风险，不能把平均分重新包装成置信度。

这套优先级仍包含经验选择：哪些盆地应受保护、每种待办多少额度、什么时候接受继续覆盖的风险。它们是需要评审和验证的策略，不是从当前有限历史推导出的唯一最优解。

## 8. 前沿如何扩展：证明边界与策略边界分开

维护两个不同集合：

- **证明候选集合Ccert**：通常包含全部未读点和原始最佳已读点。若已达到VMAX，只保留可能以同值且更优tie替代它的未读点。`Lcert=min(Ccert)`。
- **当前受保护盆地集合**：有已读结构支持且尚未完成验证的若干区间。其左界只是一条经验风险边界。

严格模式使用`r_new≤Lcert+199`。默认研究模式可以使用盆地的经验边界，但必须记录它放弃了哪些仍在Ccert里的位置。不能把“盆地未被选中”改写为“它不可能是真峰”。

向右扩展前，列出所有会被新r排除出正分条件的目标位置或盆地。优先检查其最关键未读小单元。如果右盆地出现更高原始值，旧的**已读点**可以被正式击败，但旧盆地里未读的点仍不能据此整体排除。若要仅凭右侧强回升释放边界，这属于可选的风险策略，应独立验证，不能默认为安全动作。

若始终保留所有左侧未知点，则会丧失远端覆盖；若放弃它们，又会在某些数组上不可逆地零分。这个取舍无法由控制器命名解决，默认风险释放条件是本设计最重要的开放问题之一。

## 9. 停止、切换及N的作用

停止分三类，报告应区分：

- **证明停止**：数值上界及tie证书成立，或全部位置已读且路线合法。
- **资源停止**：新动作无法连同停车满足Q/O/时间要求。
- **经验停止**：活跃盆地的约定原值核查、竞争检查及有限间隙审计已完成，控制器不再为剩余未知区付费。此时仍有残余漏峰风险。

`best±3已读`不是全局停止证据。显著性消失也不自动清除先前真实下降观测；应重新评估该证据的采样跨度和适用性。出现更高原始点、竞争谷被解析、预测被新点反驳或覆盖边界接近危险线时，重新分配动作，不要求等待一个固定粗搜阶段结束。

N只用于资源和坐标：

1. 若`N+1≤199`且全扫描加停车路线可行，可以选择穷尽，原因是信息预算足够，不是某种长度对应某种峰型。
2. 其余情况根据覆盖额度估计初始分辨率，如`h0≈(N-1)/q_cover`，再在少数尺度中取值；实际步长随观测证据和风险边界调整。
3. N参与归一化位置、预计覆盖成本和tie中央位置，不直接将N映射为“平滑、单峰或多峰”。

初始分辨率和错相点如何选择也要单独验证。本轮相位试验已经表明改变采样布局会显著改变正式成绩；不能仅凭“自适应更先进”断言换掉8格骨架一定提分。

## 10. 伪代码

```text
初始化原始缓存、运动账本、空隙账本、盆地及有限待办额度
读取少量起始锚点，所有读取经过唯一账本入口

while 可以合法结束交互:
    facts = 从原始缓存纯函数提取带来源/跨度/有效性的空间证据
    update_intervals_and_basins(facts)       # 仅新观测产生状态转移
    update_obligations_and_frontier_risks()

    if exact_certificate() or no_budget_for_action_plus_parking():
        break

    actions = {
        覆盖下一小段骨架, 补所选空隙, 核查盆地,
        同方向比较竞争盆地, 中央tie检查, 停车
    }
    为每个动作列出点集、两种单调方向、可能新赢家及停车路线
    删除违反协议/Q/O/时限或所选风险模式的动作
    按紧迫待办、能解除的证据缺口及完整路径成本选择动作

    if 选择停车或没有可承担动作:
        break

    执行选中批次的下一点；刷新输出，读取固定原始值
    更新运动账本、原始最佳点和相邻空隙
    if 新赢家/预测反驳/风险事件:
        丢弃尚未执行的旧批次并重新规划
    else:
        在短批额度内继续，随后重新规划

如果当前位置不是原始最佳点b，真实查询b
DONE
记录停止类别、未决空隙、被经验放弃的盆地及实际轨迹
```

停车始终使用所有已观测原始值中的最大者及正式tie规则，不选择平滑峰、拟合顶点或已知较低但更容易满足R的点冒充正确目标。最后停车仍可能因未知真峰而d>3；控制器必须如实承认。

## 11. 可实现性和复杂度

N≤1000、Q≤199，完整原值缓存可用O(N)，基本空隙和观测有序表为O(Q)，盆地及待办也为O(Q)。保留全部原始高点和归档盆地不需要复杂内存结构。

采用固定少数尺度S、滑动有序窗口时，每次重建多尺度统计约`O(S*m*log m)`，m为当前已读点数；全程约`O(S*Q²*log Q)`。简单原型若为每个点独立收集并排序窗口，会放大到约`O(S*Q³*log Q)`，应先检查耗时，不能把它当成免费特征。

候选动作数由活跃盆地数和少量空隙待办限制。每动作最多k个点，用两种一维单调次序并枚举可能赢家做停车审核，约O(k²)。不需要对访问顺序做旅行商退火；搜索重点是“哪些证据值得读取”。保留内部时间截止线，为最后真实停车预留余量。

## 12. 与当前实现最关键的三项结构区别

1. **搜索状态不同。** 原始b之外，有持续存在的空隙、盆地和未履行待办；近峰与低端点未知区不会仅因某个最佳点/聚类半径而消失。
2. **覆盖与核查统一调度。** 分辨率、补空隙、竞争验证和方向批次共同规划；不再由固定8格覆盖结束后才把剩余点交给一个精修池。
3. **停止依据和运动代价显式化。** 每次承诺新动作就审核停车、反向及前沿牺牲；局部核查完成和全局证明严格分开。模型一致或场景平均得分不能绕过未决证据待办。

仅把现有循环改成12次后重建pool，或把scout换成另一个系数，不构成上述架构的实现。

## 13. 仍未解决及实现前应取得的证据

- **默认前沿风险释放。** 什么时候允许牺牲旧盆地以寻找远端更高峰，尚无从官方总分恢复出的可靠规则。必须与严格模式、保守默认模式分别报告。
- **单点尖峰。** 有限审计只能减少特定遗漏，不能提供任意尖峰保证。应保留同观测、不同真实目标的对照，不以“噪声”删除失败。
- **盆地容量与额度。** 最多3个活跃盆地、各类待办额度及切换规则仍待验证；过小会遗漏竞争，过大增加Q和往返。
- **骨架稳定性。** 同一曲线插点、密采样和错相后，哪些特征应稳定、哪些应变为未解析，需先用机制实验确定。
- **相关扰动与宽平台。** 相邻点不提供同等独立证据；平台边界未读时的中央tie处理仍可能耗费大量查询。
- **总体收益。** 新结构可能减少零分，也可能因更谨慎验证普遍增加成本。应分别记录新增零分、修复零分、Q/M/O/R/d损失，不能只报合成均分。

建议先评审状态、待办及风险边界是否足够明确，再实现最小控制器：原值账本、基本空隙、两个竞争盆地、三类动作和完整停车审核。先验收它是否真实消除了一个预先指定的错误置信，再增加多尺度模型。后续任何正式比较都应使用冻结源码和明确的独立验证计划；本文没有提出自动恢复上传。
