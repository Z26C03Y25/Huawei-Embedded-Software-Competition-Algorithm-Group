> 历史文档：本文描述 159487/153592 两版。当前 main.cpp 已更新为正式 199291 分版本，参数与结果以《持续线上优化总结.md》为准。

## 1. 执行链路

```text
Solver::run
  ├─ N≤198：单调完整扫描，再真实停车（仅用于小输入/协议样例）
  └─ 正式长度：explore → refine → finish
                    ↑         ↑
                 features   pool → selectPlan → orient

所有真实读取：sample → readReal → canRead
停车读取：finish → readReal(terminal=true) → canRead
```

sample 的缓存命中只取已有数据，不改变电机位置。finish 在当前位置不是最佳已观测点时实际再次查询该点；它不隐含追加整段邻域扫描。

## 2. 强制预算

### 查询数

普通查询始终预留一次停车，最多执行至 198 次；最终停车至多增加一次，总量不超过 199。精修点集合先去重并排除缓存，再按总预算截断。所有阶段共用 q，不存在绕开账本的精修查询。

### 振荡数

canRead 模拟下一次真实移动，以及返回当前已观测最佳点的移动。新应答只可能保留原最佳点，或令新查询点成为最佳点；两种情况都有合法停车路径。

routeSafe 对完整精修计划模拟方向，并为任意新最佳点的最终返回保留一次反转。orient 比较点集两个单调方向的移动和停车成本。每个实际动作仍再次经过 canRead，不能依靠计划阶段的一次检查替代执行检查。

零位移保留最后非零方向。默认前探递增，第一轮精修优先递减；需要第二轮时重新组批，不在每个下降点即时来回精修。

### 冗余：两种明确不同的模式

默认使用模型边界：出现显著结构后，取整个竞争高值区及其左侧未查间隔作为左锚，前探上限为该锚加 180；所有跳跃先裁剪到上限。原始最高点不等于安全左锚。没有显著结构时，不把噪声或一个量化级差误认为主峰。

模型边界不能证明任意隐藏主峰的真实冗余合格。默认模式可能因隐藏左峰、远处第二峰或大范围无结构数组而零分。

`--strict-redundancy` 则维护目标位置的证明候选超集：未查位置加上已查最佳点；遇到数值上界时，再排除平局优先级不可能胜出的未查位置。取该集合最小位置 Lcert，每次读取都要求新历史最右位置≤Lcert+199。由此保证真实冗余≤199，但可能无法搜索到较远的主峰。

两种模式都严格控制查询数和振荡数。不存在对任意题面合法数组同时保证全局命中和三项约束的有限查询算法。

## 3. 决策状态与参数

features 根据实际采样间距计算斜率，用三点插值残差的 MAD、局部 MAD 和绝对残差中位数形成波动尺度。保留绝对残差项，避免量化/截零的背景把噪声估计压成零。它仍是启发式估计，不是题面噪声上界。

状态为 flat、rising、falling、smooth、broad、multi、rough。普通切换需要连续证据；明显多峰或结构矛盾立即降级。实际触发条件同时读取新鲜特征，避免滞回状态阻止必要安全动作。

当前参数是首个实现的候选值，均可后续通过独立数据验证：

- 初始位置 0、4、12、24，随后常用步长 8/12/16。
- 粗采样最多 88 次；无峰区夹逼且持续上升时，步长兼顾剩余粗采样额度与到达右端的能力。
- 显著性保留原始对比度超过 max(4,12×波动尺度) 的通道；至少 7 个观测时，另允许三点中值趋势的最高值减其 20% 分位背景超过 max(4,6×波动尺度)。后者只影响搜索决策，原始值仍决定停车。
- 模型竞争区容差为 max(1,3×波动尺度,4%×对比度)。
- 普通峰后侦察距离在 96～144 内按左侧半高宽变化；左边界可信下降有独立早停。
- 宽区先给分离候选最低机会，再兼顾原始优先级和分层覆盖。
- 最多两轮精修。第一轮候选超过剩余预算时，保留一部分额度给第二轮新信息。

完全相同的采样历史不能区分常数数组和更远处尚未出现的峰。默认长期平坦前探期限为较小中央下标加 199，并实际查询中央位置；若真实数组恒定，冗余恰为 199 而不是 200。它不证明隐藏主峰安全。`--late-flat` 放宽此期限到右端，交换常数数组的冗余保护来寻找更晚的峰。

## 5. 内部模拟退火

仅在候选点多于本轮额度时启用，避免在简单小区间引入无用计算。

1. 高优先级近邻与分离峰代表点优先，其他额度按空间分层分配。
2. 从已观测点生成 6 个虚拟完整曲线情景：分段插值及不同的间隙扰动，所有已查值保持不变。
3. 每个计划按真实查询数、完整移动、反转、模拟停车、模拟目标及冗余计算得分，另加小幅覆盖项。
4. 使用 L01—L08 进行最多 112 次内部邻域尝试，保留最好可行计划；这 112 次不是题目的搜索步数。
5. 查询数/反转数不合格的计划直接拒绝，不通过退火罚分放宽。
6. 只执行当前阶段计划，真实应答到达后重新构建候选区和后续计划。

情景集合不是经校准的真实场景分布，其得分不能称为正式期望分。未观测右侧暂按背景补全，因此该退火器主要优化已探索区内的精修；全局右探由 explore 的独立分支和前探预算控制。

随机种子由固定初值、N 和已观测数据更新，相同有效交互可重放。不重复读取同一个位置取均值；真实数组固定，重复读只会增加代价。

## 6. 运行方式

```powershell
g++ -O3 -Wall -Wextra -Wpedantic -std=c++17 main.cpp -o build/main.exe
python -m unittest discover -s tests -v
python tools/local_judge.py --program build/main.exe --suite extended --seed 2026
python tools/local_judge.py --program build/main.exe --program-arg=--trace --suite smoke
python tools/local_judge.py --program build/main.exe --program-arg=--strict-redundancy --suite smoke
python tools/local_judge.py --program build/main.exe --program-arg=--late-flat --suite smoke
```

正式提交无须参数，只提交 main.cpp。`--trace` 的 JSON 写到 stderr，包含实测账本、状态访问、算子触发、证明左界和旧峰风险；stdout 只保留下标和 DONE。算子触发统计包括内部规划尝试，不能当作真实查询次数。
