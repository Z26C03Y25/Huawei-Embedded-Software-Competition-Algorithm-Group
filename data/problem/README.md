## 先抓住五件事

1. 正式数组长度为400～1000，清晰度值是固定的非负32位有符号整数范围内的整数。
2. 求解器不知道完整数组；每次输出下标后才能收到一个值。
3. 目标是原始最大值，平局优先靠近中央，再取较小下标。
4. 电机从0出发，最后一次真实查询决定停车位置。
5. Q≥200、振荡≥7、真实冗余≥200或停车误差>3会零分；其余协议、时间和资源要求仍需遵守。

题面长度12的示例用于说明协议，不是正式数据长度。完整规则优先参考原始 PDF；仓库的教学推导和合成数据见[概念讲解](../../docs/concepts/problem-and-score.md)。
