## 第一候选：prior_corridor_stride2

- 保留216258版的0、4、12、24种子、8格结构锚点、早停、精修和停车。
- 只在50–100和500–550，把相邻8格锚点之间的偶相位位置按2格单调补读。
- 插点参与原始最大值和平局竞争，但从结构噪声/趋势草图中排除，避免混合间距
  被误判为噪声。
- 插点不增加向右运动距离；最多40次，单独计入粗搜额度，仍保留最终停车。
- 早峰一旦满足原版已解析下降条件，仍会在进入第二走廊前停车，避免真实冗余。

## 正式验证顺序

1. 先测stride2双走廊整体，判断位置先验是否能转化为净总分。
2. 若提升，拆分50–100与500–550，确定收益来自哪个盆地，再测试组合。
3. 若下降，优先拆分走廊而不是调全局步长；查询成本和精修挤占可能只发生在
   其中一个盆地。
4. 不复测相同SHA，不用本地合成总分替代正式总分。
