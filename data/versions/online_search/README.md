# 在线实验目录怎么读

[版本总览](../README.md) · [正式实验记录](../../../docs/持续线上优化记录.md)

文件保留原路径，以兼容历史记录和生成工具。无需按文件名逐个阅读。

| 文件模式 | 意义 |
| --- | --- |
| scored_分数_哈希前缀.cpp | 与一次正式评分绑定的源码归档 |
| r*/s*/g*/h*/f*/t*.cpp | 某一轮开发或消融候选，文件名本身不是成绩证明 |
| 同名.json | 参数、源码哈希与生成时路径 |
| results.json | 已登记的正式实验；配合总记录阅读 |
| final_summary.json | 2026-10-25这一轮结束时的最高分和额度快照 |
| queue*.json / next_queue.json | 历史队列或待研究方案，不是运行授权 |
| controller.json | 某次控制器状态，克隆后不能当成自己的当前状态 |
| offline_model_*.cpp/json | 离线模型实验，不能赋予未经确认的正式分数 |

先读正式总结，挑一对有明确父版本的候选比较，再看参数。某些早期记录缺少完整父版本信息；不要把跨上下文分差归因于单个参数。

旧manifest中的绝对路径只用于追溯。新实验应记录自身环境，并按[贡献规范](../../../.github/CONTRIBUTING.md)提交可重现证据。不要原地改写scored源码。
